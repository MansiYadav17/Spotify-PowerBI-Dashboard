# Spotify Analytics Dashboard 🎵

## Project Overview

This project presents an interactive Spotify Analytics Dashboard developed using Power BI. The dashboard provides insights into song popularity, artist performance, album distribution, and music trends through dynamic visualizations and KPI metrics.

## Objectives

- Analyze Spotify music data efficiently
- Track song popularity and artist performance
- Compare album types and explicit content distribution
- Identify trends using interactive visualizations
- Support data-driven decision making

## Tools & Technologies

- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset
- Data Visualization

## Dashboard Features

### Overview Page
- Distinct Songs KPI
- Count of Artists KPI
- Average Duration KPI
- Average Popularity KPI
- Songs by Artist Analysis
- Songs by Album Type Analysis
- Explicit vs Non-Explicit Distribution
- Popularity Trend Analysis
- Distinct Songs Trend Analysis

### Artist Analysis Page
- Artist-wise Song Distribution
- Artist Popularity Comparison
- Performance Insights

### Songs Analysis Page
- Song-Level Analytics
- Popularity Distribution
- Duration Analysis
- Comparative Insights
